# Homeostat

**Regulatory-deficit medicine: annotation-blind mechanism discovery under an oracle
ensemble.** Named for Ashby's homeostat — the device that finds its own equilibrium —
because the object of study is regulation, established per individual.

## The claim, in three sentences

Allopathic diagnostics scores individuals against population-derived reference
distributions and has no per-individual reference-establishment step; this failure is
invisible for lesional disease and maximal for regulatory disease, which presents as
deviation in degree against a baseline the apparatus never establishes. Single-variant
statistical genetics must fail on this phenotype class for structural reasons (flux
control is distributed and redistributes under load; the effect exists in composition,
not at loci). The program inverts the method: recover coupling structure with
annotation held out, validate by recovering known annotation without having used it
plus selection-signature enrichment, and search under a candidate-set filter (E/I/R,
PBS-ranked) that makes the descent tractable by bounding pleiotropic bridges by
construction.

**What this is not:** a traditional-medicine project. Traditional systems (Ayurveda,
TCM, with Unani as the explicit negative control) enter as *causally independent
sources of partition hypotheses* for the oracle ensemble — an idea-generating surface,
weighted by lineage phylogeny, audited by the same formal discipline as every other
carving. Nothing in the program depends on any traditional claim being true.
