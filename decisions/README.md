# Decision Log

Structured record of significant architectural and design decisions for Homeostat.
Each file captures what was decided, why, and what alternatives were considered.

## Format

One file per decision, named: `YYYY-MM-DD-topic.md`

```markdown
# Decision: [Short title]

**Date:** YYYY-MM-DD
**Status:** accepted | superseded | rejected
**Context:** What prompted this decision?

## Decision
## Rationale
## Alternatives Considered
## Consequences
```

## How agents should use this

Before proposing an architectural change, check this directory for prior decisions on
the same topic. If your change would contradict an existing decision, document why
circumstances have changed, and expect the founder to govern.
