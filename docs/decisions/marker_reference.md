# Decision: the marker reference is the population norm (the OBSERVATION), not the mechanism

Date: 2026-09-04

## The line that makes it consistent with the anti-population core

**The population enters where the read reads the SHADOW** (is this marker abnormal), **never where
it reads the MECHANISM** (which pathway the shadow implicates; the geometry reads that
population-free). This SHARPENS Law 1 rather than breaking it: Law 1 forbids a frequency becoming
the VERDICT (significance is kappa; the mechanism is data-geometry). It never forbade a demographic
reference range deciding that a pixel of the shadow is lit. Marker normality is not derivable from
structure -- a glucose of 90 is not "structurally wrong," only wrong relative to age/sex-matched
people -- so for the marker layer the reference is a population fact, and that is correct.

## BUILT (v1): the marker reference is GIVEN, not mined

A marker's reference is a PUBLISHED demographic interval `[low, high]`, looked up by
`(marker, age/sex/...)`, converted to `(center, spread)` by `producer.reference_center_spread`, and
read against by `position.place` with `k=1` (the interval IS the informational-zero band). The
reference is GIVEN, not mined -- `mine_zero`/`mine_spread` are the DISCOVERED (gene/pathway)
reference path, not the marker path. The literature table (`(marker, demographic) -> [low, high]`)
is the data seam, a fetch-shell to wire like the other banks.

## DEFERRED (a clinician's mechanistic call, recorded here so it is not lost)

The founder's own hedge: sometimes the MECHANISM predicts a marker's expected value (a gene's
effect on a metabolite's metabolism). That is a SECOND reference -- the mechanism's own structural
prediction -- and the DISAGREEMENT between the population norm and the structural prediction is
itself a signal: the cross-network "two orthogonal traversals of one atom" operator (Peitho §9).
This is out of the v1 marker producer's scope (it is a mechanistic/clinical judgement, not the
automated read's) and is recorded here as the marker layer's own future orthogonal axis.
